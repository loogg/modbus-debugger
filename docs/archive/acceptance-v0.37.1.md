# v0.37.1 正式发布验收

2026-11-26，在 Windows x64 上按[正式发布清单](../acceptance.md)验证。脚本功能提交为 [fb4a0aa](https://github.com/loogg/modbus-debugger/commit/fb4a0aac7a1b6554b4180c64fd40eb6520787af0)。测试使用隔离工作区、独立 PyModbus TCP 模拟器及 COM1 ↔ COM2 虚拟串口。串口结论覆盖 Windows 原生串口栈及虚拟链路，物理 RS485 收发器与现场设备未参与。

## 脚本与工程检查

- 启用虚拟 RTU 和软件主从闭环，串行执行全部 Vitest，88 个文件共 836 项通过，零跳过。独立模拟器的两项 Python 用例也均通过。覆盖协议与分帧恢复、主从设备、最新值与写应答、共享采样缓存、文件持久化、调度、脚本、多窗口状态、组件及更新。
- 从 Windows 剪贴板读取面板生成的源码，在独立原生 Lua 5.4 中执行。大整数运算保留 `9007199254740993`，与桌面同走 `ALARM` 分支。数字和字符串两种 T7 旧文件在修改日志、保存后依然实际触发 T7。磁盘被独占时保留旧修订，解锁后重试成功。写应答前暂停和单步均保持等待，10 ms 定时器的 8 ms 阈值在真实时钟下连续 6 次成功。[脚本专项和界面复核](../acceptance/master-scripts.md#0371-脚本复核问题修复)
- 真实 Main 的 Browser Review Mode 已检查 1440×960、1280、1279 和 1024×680 尺寸的脚本界面。内置浏览器及打包桌面均复核了运行和暂停间的按钮位置，快速继续、停止后进入「已停止」。
- 全仓 ESLint、TypeScript、文档链接及 Git 差异检查通过。`package.json` 与锁文件版本均为 0.37.1。

## 打包版业务与发行物

- 使用本次 Forge 构建的 Windows x64 程序，独立模拟器批次 23 个 WDIO 文件、109 个场景全部通过。另起进程运行 TCP、虚拟 RTU 主从闭环及泵站，两个文件分别通过 6 项和 3 项。两批合计 118 项，零跳过。
- 核对了本次打包版的实时表、模板、寄存器导入预览、原始数据抽屉、趋势与历史曲线、通信和设置界面，并检查 1440、1280、1279 和 1024 px 四种宽度。
- 空工作区首次使用和百万样本容量测试各通过 1 项，连同上述业务用例，27 个 WDIO 文件共 120 项通过。打包版打开 100 万样本会话耗时 4796 ms，打开回放 109 ms，移动游标并绘制 238 ms，导出完整 CSV 724 ms。核对了 CSV 的首尾数据及总长度 28888904。独立增长基准测得 10 万、50 万和 100 万样本库分别占 7622656、38158336 和 76333056 字节。
- 目录、ZIP、Portable、NSIS Setup 均实际启动到 0.37.1，Renderer、IPC、serialport 与历史库初始化通过。Portable 在中文及空格目录退出重启后保留数据库，Setup 在自选目录安装、重装和卸载后保留用户数据。ZIP 内 94 个程序文件均与更新清单的 SHA-256 一致，包内外清单逐字节相同。

## 自升级与验收证据

目录/ZIP、改名 Portable 和自选路径 Setup 均通过隔离 HTTP 夹具下载、校验、安装并重启至测试版本 0.37.2。工作区、偏好、历史库和未知用户文件保留。给 Setup 注入安装失败后，程序版本与安装登记均恢复至 0.37.1。0.37.2 仅用于本机测试。

本次发布对应 [v0.37.1](https://github.com/loogg/modbus-debugger/releases/tag/v0.37.1)。[功能提交的云端 Windows 构建](https://github.com/loogg/modbus-debugger/actions/runs/45759666592)已通过锁定依赖安装、Windows 构建以及发行物启动检查。本机正式验收的原始日志、容量指标和产物校验结果保存在 `out/test-temp/release-v0371/`。
