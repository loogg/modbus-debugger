# v0.35.0 正式发布验收

2026-11-25，在 Windows x64 上按[正式验收清单](../acceptance.md)验证。桌面测试使用隔离工作区和历史库。TCP 使用独立 PyModbus，RTU 使用 ELTIMA COM1 ↔ COM2 虚拟串口。本轮验证覆盖软件协议和虚拟串口链路，物理 RS485 收发器与现场设备未参与。

功能提交为 [27a72d6](https://github.com/loogg/modbus-debugger/commit/27a72d6589398c317fa912773eca31a7619cc497)，桌面闭环测试修正为 [c377087](https://github.com/loogg/modbus-debugger/commit/c37708722de6abbf2d18e88d56a9a75638e38264)。发行物对应标签 [v0.35.0](https://github.com/loogg/modbus-debugger/releases/tag/v0.35.0)。

## 事件调度与回归

- 保留 10 ms 最小周期，`on_run` 默认 100 ms，定时器提供 T0–T7。运行[独立周期示例](../examples/independent-on-run.modbus-script.json)，在 `on_run` 首次递增前暂停时，`on_start` 已计数 18528 次。单步后工作计数保持，心跳从 0 变为 1。继续后收到三次心跳，工作计数达到 61775，脚本自然结束。日志筛选保留了三条周期消息和启动段的完成消息。
- 86 个 Vitest 文件包含 816 项单元和集成用例，全部通过，零跳过。覆盖协议编解码、解析恢复、独立模拟器、主从闭环、写应答与共享缓存、工作区和历史持久化、更新、UI 组件及事件调度。另有 2 项 Python 模拟器用例通过。事件验收包含百万次循环与无限循环、异步 I/O、回调合并、定时器操作、全局断点及工作区切换。[主站脚本专项](../acceptance/master-scripts.md)
- 实际审查 1440×960 的积木与 Lua、1280×800 的断点、1279×800 的变量以及 1024×680 的紧凑布局。本次 Windows 桌面访问受限，四种尺寸通过连接真实 Main 的独立 Chromium 在 Browser Review Mode 复验。同一功能在开发验收时已通过内置浏览器完成拖放、运行与单步。
- ESLint、TypeScript、包版本与锁文件一致性检查通过。本地 Forge make 使用锁定的 Electron 33.4.11，缓存 ZIP 的 SHA-256 已与该依赖自带的清单比对。
- 分别验证了 `on_run` 与 T0 的周期边界。两者的 9 ms 配置均被校验拒绝，10 ms 配置均在 Main 中实际触发。另用 Lua 5.4 载入本轮界面生成的代码，三次心跳分别在约 100、200、300 ms 调用，当时启动协程均处于挂起态。

## Windows 发行物

本地构建生成目录版、ZIP、Portable、Setup 及更新清单。四种形式均实际启动到 0.35.0，Renderer、IPC、serialport 和历史库初始化通过。Portable 在中文和空格目录重启后保留数据库，Setup 自选目录安装、重装和卸载后保留用户文件。另核对了 ZIP 中全部 92 个程序文件的 SHA-256，包内外更新清单逐字节相同。

使用隔离的本地 HTTP 夹具验证自升级。目录/ZIP、改名 Portable、自选路径 Setup 从 0.35.0 完成下载、校验、安装、重启并进入测试版本 0.35.1。原工作区、偏好、数据库及用户文件均保留。单独注入 Setup 安装故障后，程序与安装登记恢复到 0.35.0。0.35.1 仅用于本地升级夹具。

## 桌面业务与容量

- 在打包版上核对主站脚本、点位读写、模板导入、多窗口、画布、趋势、诊断、历史和设置。实际查看了候选版的实时表、趋势与历史图、寄存器导入预览、原始数据抽屉以及紧凑窗口的截图。独立模拟器和软件自身的主从闭环分批运行，避免争用串口。
- 空工作区首次启动通过。打包版打开 100 万样本历史会话耗时 5017 ms，打开回放 103 ms，移动游标并绘制 232 ms，导出完整 CSV 747 ms。核对了 28888904 字节 CSV 的首尾数据。
- 26 个 WDIO 文件共 115 个不同场景，最终全部通过，零跳过。首轮一项 RTU 用例在写入前没有找到过滤后的 UTF8 行。修正测试以键盘替换搜索词，核对完整输入并等待当前可见页面的目标行，复跑完整 TCP/RTU 闭环文件，6 项全部通过。验证包括原生写入 UTF-8 字符串、溢出拒绝、两端确认值、原始字节和 CSV 精度。

本次正式验收的日志、截图和校验结果在 `out/test-temp/release-v0350/`，容量原始指标在 `out/test-temp/capacity/capacity-1m-smoke.json`。
