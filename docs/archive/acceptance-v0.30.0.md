# v0.30.0 正式发布验收

2026-11-23 在 Windows x64 独立工作树执行。源码版本为 0.30.0，对照[正式验收清单](../acceptance.md)。验收使用工作区副本、独立数据库、本机 TCP 和 ELTIMA COM1 ↔ COM2 虚拟串口。软件压力模型提供泵站反馈。

| 范围 | 实测记录 |
| --- | --- |
| Protocol / Domain / Main / Renderer 与打包 | 84 个 Vitest 文件覆盖 778 项互异检查。含独立 PyModbus 与软件主从互操作的 115 项串行运行，另外 661 项覆盖解析恢复、映射、写应答与确认采样、工作区命令、持久化、画布、调试器和界面，再补验 2 项发行文件锁用例。Python 模拟器另有 2 项测试通过。 |
| 主站流程与泵站 | 设定 0.36 MPa 后独立核对寄存器，现场应答、达压与卸压分步记录。验证断点前冻结待写值、单步一次下发、高风险确认、停泵与报警锁存、仅一个 Unit 无应答和整链路中断。参见[主站脚本验收](../acceptance/master-scripts.md)及[泵站联调](../acceptance/pressure-bench.md)。 |
| 界面 | 在连接真实 Main 的内置浏览器检查 1440×960、1280、1279 和 1024×680。实际启动软件从站、画布写入 0.36 MPa、单步、继续，得到达标 0.36 和卸压 0 MPa 的日志。核对实时点位、模板导航、紧凑窗口 Lua 预览、通信诊断及关于页版本。原生窗口、串口和文件对话框另在打包版验证。 |
| 容量与持久化 | 打包版打开 100 万样本的历史会话用时 4755 ms，打开回放 86 ms，移动游标并重绘 303 ms，完整 CSV 导出 632 ms。独立首启用例验证空工作区与第一个连接入口。 |
| 发行物 | 干净工作树执行 `npm ci` 和 `npm run make -- --platform=win32 --arch=x64`。四种交付形式均通过实际启动、版本、Renderer、IPC、serialport 与历史库检查。ZIP 与目录版程序相同。Portable 独立目录重启后数据保留，Setup 的自选路径安装、重装、卸载及保留用户数据均通过。 |
| 桌面回归 | 22 个常规 WDIO 文件与 2 个容量/首启文件合计 111 个场景通过，零跳过。使用独立模拟器的 RTU 用例和使用 COM 对的主从自测分批运行。暂停报文的 UTC / 上海时区复验通过。 |
| 发行目录竞争 | 在 Windows 上重现开发预览监听打包目录导致的 EPERM。将生成目录从监听范围移出后，保持预览运行，同一完整程序目录可以原子迁移。短时占用做有界重试，文件缺失立即失败并进入原有回滚路径。 |
| 自升级和回滚 | 目录/ZIP、改名 Portable、自选路径 Setup 均从 0.30.0 升级到隔离夹具 0.30.1，经历实际下载、校验、安装与重启。工作区、用户文件和数据库保留。另注入 Setup 安装失败，验证回滚后重新启动 0.30.0，并核对卸载清理。0.30.1 只在本地测试夹具中使用。 |
| 工程检查 | 锁文件与版本一致，lint、TypeScript、文档链接和 Git 差异检查通过。源码与本记录使用发布标签 `v0.30.0` 标识，最后一笔打包工具与回归修正为 `c0f744a`。 |

当前版本的可重建本地结果在 `out/test-temp/`。容量数据在 `capacity/capacity-1m-smoke.json`，发行物截图在 `release-smoke-screenshots/`，桌面操作与故障证据在各专项 evidence 目录。
