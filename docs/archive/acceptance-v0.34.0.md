# v0.34.0 正式发布验收

2026-11-25，在 Windows x64 上按[正式验收清单](../acceptance.md)验证。所有桌面测试使用工作区副本和隔离数据库。TCP 使用本机独立 PyModbus，从站与主站的 RTU 测试使用 ELTIMA COM1 ↔ COM2 虚拟串口。物理 RS485 收发器和现场设备未参与本次验收。

软件功能提交为 [9f38bc1](https://github.com/loogg/modbus-debugger/commit/9f38bc1fa4e5fb613ece31004d65681096788aa3)，桌面写入用例修正为 [1d55b58](https://github.com/loogg/modbus-debugger/commit/1d55b5860bda8a7b661c73969682a4645bb2f502)。公开发行物使用标签 [v0.34.0](https://github.com/loogg/modbus-debugger/releases/tag/v0.34.0)。

## Windows 发行物

使用 `npm run make -- --platform=win32 --arch=x64` 生成目录版、ZIP、Portable 和 Setup，并生成自升级清单。单独核对了本地 ZIP 中 92 个程序文件的 SHA-256，包内清单与外部清单逐字节一致。

- 四种形式均实际启动到 0.34.0，Renderer、IPC、serialport 与历史库初始化通过。ZIP 与目录版的应用包内容一致。
- 单文件 Portable 在含中文和空格的独立目录运行，两次启动保留同一数据库。Setup 自选路径安装、重装和卸载通过，卸载后预置的用户文件保留。
- 使用隔离的本地 HTTP 夹具验证从 0.34.0 升至测试版本 0.34.1。目录/ZIP、改名的 Portable 和 Setup 均完成实际下载、校验、安装和重启，保留原工作区、偏好、历史库与用户文件。另行注入安装失败并验证恢复 0.34.0 及其安装登记。正式发布版本为 0.34.0。

## 桌面业务与容量

- 在目录版中实跑独立模拟器的 TCP/RTU 脚本读写，并另用一轮独立进程运行软件自身的 TCP/RTU 主从闭环和泵站工况，避免争用串口。核对了断点处动态写入的实际值、单步、确认回执、失败恢复和可读点位的设备反馈。
- 用隔离数据目录启动空工作区并建立第一个连接。对 100 万个数值样本，打开历史会话耗时 5285 ms，打开回放 128 ms，移动游标并完成绘制 265 ms，完整 CSV 导出 711 ms。已核对 CSV 总量及首尾数据。
- 实际查看了打包版在四种窗口宽度的设备拓扑、实时数据表、模板、诊断、趋势和历史界面，以及原始数据抽屉和导入预览。独立窗口、串口和桌面文件操作由原生回归覆盖。
- 25 个 WDIO 文件合计 113 个不同场景，最终全部通过，零跳过。首次运行有两项写入检查失败。只写命令回显 `199` 时，旧断言误接受了末尾的 `99`。写前读取异常用例也未出现预期的「未发送」状态。修正测试的键盘替换操作，在提交前核对完整输入，并通过 Main 核对成功命令的精确值。重新执行这两个文件的全部 6 项，覆盖原生弹出和回入、设备异常及超时后恢复。

本轮日志与本地产物校验结果位于 `out/test-temp/release-v0340/`。百万样本的原始指标位于 `out/test-temp/capacity/capacity-1m-smoke.json`。
