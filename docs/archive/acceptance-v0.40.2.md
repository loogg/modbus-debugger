# v0.40.2 正式发布验收

2026-11-27，在 Windows x64 上按[正式发布清单](../acceptance.md)验证。本次验收代码为 [1bf5bf9](https://github.com/loogg/modbus-debugger/commit/1bf5bf98c5089f888d50d61809b653cdd41f0da3)。设备测试在独立工作区内使用 PyModbus TCP 模拟器和 COM1 ↔ COM2 配对虚拟串口，物理 RS485 设备未参与。

## 脚本、画布与工程检查

- 全量 Vitest 启用独立 RTU 模拟器、软件主从闭环，按单 worker 执行。93 个文件共 863 项全部通过，零跳过。独立 Python 模拟器的 2 项测试通过。全仓 ESLint、TypeScript、文档链接、Git 差异、包版本和锁文件一致性检查通过。
- 本版覆盖画布按键与多窗口事件配对、共享变量与脚本末值、确认采样变化、逐 Unit 上线和离线、Lua 调度和断点，以及编辑器与 Main 的点位校验。内置浏览器已在同一候选代码上复验异窗保存期间的真实按下和松开、停用绑定的位置与原因、重新启用及改绑。定向结果见[主站脚本验收记录](../acceptance/master-scripts.md)。
- Forge 使用锁定版本 Electron 并在构建前比对缓存 ZIP 与依赖随附的 SHA-256。Windows 目录版、ZIP、Portable、Setup 以及应用所用的更新清单由同一次正式构建产生。

## 首轮失败与复验

- 在 1024×680 窗口运行「连续三次温度超限告警」，停在 `log_overheat` 断点并展开调试详情。「公开」复选框挤占行宽，导致 `current_temperature` 换行，最后一个观察值超出面板底部。修正紧凑布局的列宽后，内置浏览器和打包版都同时显示主流程、`exceeds_limit`、`log_overheat` 的六个值。内置浏览器实测依次为 `3、74、74、70、74、70`，主流程两行都能操作「公开」。
- 实时曲线滚轮缩放与工具箱拖接各有一次未达到预期。补录时观察到滚轮可能落在提示浮层上。桌面测试改为命中可见绘图区后滚动，并在拖接时根据 Blockly 拖动层和目标积木的实时位置松开鼠标。继续验证实时采样推进、嵌套关系、保存后的积木图和实际设备读写。上述三个完整测试文件共 10 项通过。

## Windows 发行物

目录版主程序、Portable 和 Setup 的 Windows 产品版本均为 0.40.2。校验了 ZIP 的全部 94 个程序文件与清单 SHA-256，包内 `resources/app-files.json` 与独立更新清单逐字节相同。GitHub 的 Windows 构建从锁文件安装依赖后，重新生成了发行物，并通过四种形式的启动检查。[Windows 构建记录](https://github.com/loogg/modbus-debugger/actions/runs/45959167106)

本机分别启动目录版、ZIP 解压版、单文件 Portable 和 Setup 安装版，核对 Renderer、IPC、原生串口模块与历史库初始化。Portable 放入含中文与空格的目录，退出并重启后历史库仍在。Setup 通过自选目录安装、启动、重装与卸载，用户文件保留。

## 自升级与验收证据

目录/ZIP、改名后的 Portable 和自选路径 Setup 均从隔离 HTTP 服务下载、校验、安装并重启至测试版本 0.40.3。工作区、偏好、历史库和自建文件均保留。向 Setup 注入安装失败后，程序及安装登记恢复至 0.40.2，旧工作区仍可打开。0.40.3 仅用作本机升级夹具。

本机首轮、复验、发布候选的逐项日志及校验数据保存在 `out/test-temp/release-v0402/`。`final/verified-gates.json` 核对了仓库全部 29 个桌面测试文件和 126 项通过结果，零跳过。公开附件与版本记录见 [v0.40.2 发布页](https://github.com/loogg/modbus-debugger/releases/tag/v0.40.2)。
