# 主站积木脚本

## 范围与验收基线

- 主站脚本使用 Blockly 工作区。用户可新建、保存、导入和导出流程，并查看生成的 Lua。保存采用工作区内独立脚本 ID 与修订号。
- 积木覆盖开始、等待新采样、读取到变量、写入点位、等待条件、断言、延时、条件分支与限次循环。条件可使用从站通信状态、设备确认值和运行变量，并支持与、或、非。积木通过稳定 ID 定位工作区中的主站从站和点位。
- Main 校验并执行保存的积木流程。保存变量与判断直接使用共享 Block Cache 中当前有效的确认值。等待步骤接收采样或状态通知并支持超时。写入经既有调度和应答结算，需要写后新值时显式接「等待新采样」。高风险写入在运行前显示设备与写值并获得确认。
- 运行显示当前及各已完成步骤、结果和失败原因。停止阻止后续步骤及仍未发出的写入，已发出的请求按原规则结算。离开页面可继续查看同一次运行，退出和切换工作区结束本次运行。
- 导入的流程按共享契约校验。已有工作区可照常加载。Main 执行的是受检积木流程，Lua 面板供预览与复制。

## 验证计划

- 定向覆盖保存冲突、旧工作区、失效绑定、不可写点位、写应答与采样、新旧值隔离、超时、停止与高风险确认。
- 使用独立 TCP 模拟器验证运行链路。Browser Review 实操编排、保存、运行、失败、停止和重载，核对常规与紧凑尺寸。使用原生或目录版验证沙箱 IPC、文件进出及启动。

## 0.27.0 组合条件与运行变量

- 「条件」提供可嵌套的「与」「或」「非」和「与变量比较」，均可用于等待、断言或分支。「设备操作」提供「读取到变量」，并将原读取积木显示为「等待新采样」。已保存流程可直接打开和执行。
- 读取到变量等待积木开始执行后的新确认采样，保留数值、布尔值或字符串类型。变量按名称在本次运行内共享，重复读取到同名变量会更新它。比较使用实时确认值和已保存的变量值，未赋值或类型不兼容时报告具体原因。
- 组合条件保留点位值暂不可用的状态。与条件可在任一项确定不成立时判定为不成立，或条件可在任一项确定成立时判定为成立。非条件继续等待不可用的值。
- 定向验证组合逻辑、运行隔离、超时、实际写前采样与写后比较、保存与重载、Lua 预览。用隔离目录版和模拟器核对写应答、后续采样、积木操作与可视状态。

- TypeScript、定向 ESLint、文档链接与差异检查通过。9 项脚本 Unit/Integration 和 7 项隔离目录版端到端用例通过。定向覆盖同名变量覆盖、下一次运行变量清空、未赋值、布尔与数值类型不一致、组合短路、不可用值及旧读取积木。
- TCP 在目录版界面拖入积木，绑定目标转速并输入变量名。Lua 预览显示读取到变量、写入及等待新采样。运行日志保存写前值 1500，独立模拟器客户端确认保持寄存器 6 写后为 1683，核对了实际 FC06 应答和主站确认值。
- COM1 ↔ COM2 虚拟串口导入嵌套条件流程。第一轮比较匹配保存的工程值 1.7 并写入，第二轮使用新采样 25.4 进入另一个分支。实际只发出一次 FC06，后续 FC03 读回原始寄存器值 254。最终的「与」「或」「非」组合条件通过，核对了 Lua 预览及对应日志。
- Windows 锁屏阻塞内置浏览器审查。使用 Playwright 在 Browser Review Mode 连接真实 Main 和独立 TCP 模拟器，在 1440×900 核对嵌套积木及 Lua 预览，在 1024×680 核对托盘和运行结果。界面保存并运行四步组合断言，独立客户端读回 1683。已查看该流程与目录版的实际截图。

## 0.27.1 变量比较使用最新确认值

- 「与变量比较」从 Main 的共享 Block Cache 取该点位最新的有效确认值，允许使用本次运行开始前或最近一次写入前已取得的确认值。暂无有效值时由外层等待条件、断言或分支处理超时。
- 要用写入后的反馈做比较时，在写入后对反馈点位接「等待新采样」。定向复现写入 A 后立即用 B 点位的已有确认值比较，并用隔离 TCP 与虚拟 RTU 模拟器复测显式采样后的判断和 Lua 预览。

- TypeScript、定向 ESLint、文档链接及差异检查通过。10 项脚本 Unit/Integration 通过，包含写入 A 后，B 在本次运行暂无新采样时使用已有确认值完成比较。
- 0.27.1 隔离目录版的 2 项端到端用例通过。TCP 从界面编排并读回 1683，虚拟 RTU 流程在写入后显式等待采样读到 25.4，下一轮按新值进入延时分支，实际只写入一次。核对了 Lua 预览、运行日志和协议应答。目录版构建使用已安装 Electron 依赖自带的 SHA-256 校验值验证本地缓存包。

## 0.28.0 显式等待与 Main 通知

- TypeScript、相关 ESLint、文档链接与差异检查通过。42 项定向 Unit/Integration 通过，包含无新采样时的即时取值、同一轮事件中短暂成立的条件、本笔采样的地址覆盖、从站离线及恢复后的唤醒，以及成功、超时、停止后的订阅释放。
