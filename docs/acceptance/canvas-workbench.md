# 自由组态画布与多窗口工作台

需求依据：2026-11-11 用户确认自由摆放控件并绑定点位、每个页面可弹出和回入、同类页面允许多实例，随后授权实现。分支 `codex/canvas-and-detachable-tabs`。

## 编辑态本地预览（0.16.0）

用户确认实施控件状态预览。编辑器提供跟随设备与本地模拟，模拟状态保存在当前画布视图的临时状态。

- 指示灯可选择亮、灭、各条规则及未匹配默认状态，也可输入数值检查匹配。仪表提供模拟值及最小/中间/最大快捷值。
- 数值、文本、开关、枚举及曲线可使用模拟数据，按钮和输入可检查正常、禁用、写入中、失败外观。
- 画布控件和编辑器明确标记预览。预览输入、按钮等交互受编辑器约束，设备写入入口继续校验编辑态，模拟数据独立于 AppStore 确认快照、live、Recorder 和 Main。
- 单控件可恢复跟随，工具栏可清除全部预览。进入运行、切换画布或关闭视图清除预览，弹出/回入保留当前编辑视图的预览，工作区保存/导出仅包含正式定义。
- 验证覆盖模拟值与确认值隔离、强制状态/默认状态、正常/写入中/失败外观、编辑态写入拦截、运行恢复真实值，以及 Browser Review 和打包版原生窗口。

## 本轮补充要求

用户在实际使用后指出控件卡片化、尺寸和留白过大，并追加容器、独立文字标签和专业可商用曲线要求。本轮继续实现：

- 基础控件默认透明、无外层卡片，名称标签/背景/边框按需开启；按控件种类提供紧凑尺寸与“适合内容”，绑定说明收进属性区/提示，异常与写入状态仍可识别。
- 文字标签为独立控件。容器保存真实父子关系，子控件使用相对坐标；支持加入/移出、整体拖动、分组/解除、复制删除和持久化，拒绝循环/缺失父级及越界。容器默认仅用轻量边界表达分组。
- 沿用 Apache-2.0 的 ECharts，曲线增加多信号、图例显隐、缩放/平移、十字游标、暂停/跟随与单位坐标轴，继续复用同一缓存。暂停图形保留采样副本，不让滚动缓冲淘汰已暂停的曲线。
- 新增验证：紧凑控件不再预留标题/绑定页脚；容器移动子项位移一致、解除容器保持画布位置；嵌套关系与复制 ID 验证；曲线多信号、交互、暂停与恢复；Browser Review 和 Native 实际复验。
- 用户追加控件库图标与画布颜色入口。控件库改为图标配短名称，工具栏提供背景色板和自定义颜色，保存与撤销沿用画布草稿。原生复验发现已移动 DOM 的跨窗口类型判断阻挡拖动，改用 Pointer Capture 处理拖动并直接集成 MIT 的 `re-resizable` 进行尺寸调整，补充弹窗内拖动和尺寸回归。

## 范围与方案

- 多标签工作台覆盖全部既有功能页与新增画布；可打开副本，各实例独立选择设备、筛选、编辑和浏览。
- 弹出/回入移动同一视图，保留草稿、滚动与曲线；独立窗口关闭默认回入，标签关闭才销毁页面。主窗口关闭处理未保存草稿并退出所有窗口。
- 使用稳定 DOM 挂载点与 React Portal 保留视图树；原生窗口由 Electron Main 管理并限制到应用自身的窗口宿主页。跨窗口弹层、键盘与拖动使用所属 document/window。后台数据仍只订阅一次，不创建额外 Runtime/Poll。
- 每张画布保存名称、尺寸、控件布局、样式和点位引用；多个视图共享定义，视角独立。画布编辑使用草稿、明确保存和版本冲突检查。
- 控件包括文字标签、数值、指示灯、按钮、开关、数值输入、仪表、趋势图和容器。编辑/运行分离，支持拖入、移动、尺寸调整、多选、对齐、复制、图层、撤销/重做、删除和点位属性配置。控件库使用对应图标，画布背景可从工具栏设置。
- 点位按设备实例和点位 ID 绑定，显示 confirmed value 与通信质量；写控件使用既有 `point.write`，尊重只读、高风险确认、pending/失败反馈。图表复用同一已确认数据流。
- Main 接收画布的细粒度批量编辑命令并校验 revision；不接收完整 Workspace。画布和工作台布局随工作区保存；窗口坐标仅存本机偏好。兼容旧工作区导入。
- 尺寸调整使用 MIT 的 `re-resizable`，拖动通过所属窗口的 Pointer Capture 处理。本次功能版本按项目规则递增至 0.13.0，目录版用于原生 Smoke/E2E。

```text
Main: Runtime / Block Cache / Workspace / Window lifecycle
  | snapshot + delta                ^ typed commands
  v                                 |
Shared renderer data ---- View A state ---- docked DOM mount
                     +--- View B state ---- native window DOM mount
                     +--- Canvas view ----- canvas draft -> revision checked edits
```
