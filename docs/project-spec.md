# 产品与领域规范

实现机制见[架构](architecture.md)，报文格式与分帧边界见[协议说明](protocol/01-application-protocol.md)；本文件只规定产品与领域行为。

## Domain Model

`Connection → Slave Instance → Device Template → Block → Point`

Connection 可选择 `master`（主站 / Client）或 `slave`（本机从站 / Server）；旧工作区未指定角色时按主站运行。两种角色可在不同连接同时使用，同一连接只承担一个角色。

- Slave 只绑定 Template，不复制模板结构；Unit ID 属于 Slave，不属于 Template。
- Block 是实际轮询单元：地址区、Start、Length、默认周期；同 Template、同地址区 Block 不允许重叠。
- Point 是 Block Raw Memory 的解释视图；Point 允许重叠并共享同一 Block Cache。
- Point 类型：Int / UInt / Float / Bool / Enum / String。
- 读取地址区：Coil(01)、Discrete Input(02)、Holding Register(03)、Input Register(04)；02/04 固定只读，01/03 可按 Point 配置写权限。
- 写 Coil 使用 FC05 / FC15，写完整 Holding Register 使用 FC06 / FC16，只写寄存器的部分位/字节使用 FC22（0x16）掩码写。
- 核心 UI 和通信日志使用 0-based PDU 地址；PLC Reference Address 只在 Import 层转换。

## 本机从站

- TCP 使用本机地址和端口监听，RTU 打开指定串口；创建和加载从站连接后默认停止，用户点击“启动从站”才开始响应。停止会关闭全部客户端/监听器或串口，启动失败显示实际错误；自动恢复仅作用于已启动的连接。
- 一个连接可配置多个 Unit 1–247，复用已有 Slave Instance 与 Template。只响应启用、已绑定数据块的实例，Unit 的内存相互独立。数据块地址均为 0-based，连续块允许跨块访问，缺口和越界返回异常 02。
- 支持 FC01/02/03/04/05/06/15/16/22。外部主站可写 Coil / Holding Register，本地“从站内存”可设置四类数据区。请求先完整校验，批量写入按完整范围原子提交，非法功能码返回 01，非法数量、值或 PDU 长度返回 03。FC22 在本机内存中原子保留掩码以外的位。RTU Unit 0 广播写更新所有启用且支持该范围的实例，广播请求一律不响应。
- Main 的 Block Cache 是本机设备的实际内存，Realtime / Trend / Canvas / 采样缓冲 共用；从站不发起 Poll。界面输入是草稿，命令成功提交后才发布确认值；主站模式的缓存不得用于 RMW 的限制不变。
- 新数据块初始化为零。停止/启动保留进程内当前值；“保存为启动初始值”将当前从站全部数据块保存至工作区（首次保存自动分配文件），应用重启恢复匹配的数据区初始值。外部写入不会自动覆盖保存的初始值。地址、类型、长度或绑定改变时重新初始化对应内存，防止旧设备值污染新定义。
- 从站连接不提供主站扫描/临时读取/主动刷新，Main 同时拒绝这些调用。通信诊断中请求为 RX、响应为 TX，保留 Unit、FC、TID、ADU/PDU、处理耗时和异常；TCP 客户端断开不会将仍在监听的从站标为离线。

## Point Mapping

至少表达 register offset/count、raw type、byte/word order、byte selector、bit offset/width、String length/encoding、display format、Enum map、Scale/Offset、unit、access、high-risk write confirmation。

数值点位可设置显示精度，即**最多小数位数 0–12，默认 3**。实时确认值、趋势 Tooltip 和历史回放按该点位精度格式化；Block Cache、工程数值、记录样本及 CSV 导出保留未舍入的原值。记录会话的 Schema Snapshot 保存当时的精度，后续模板修改不改变旧会话显示。

主从或多个设备使用同名信号时，趋势、历史状态轨迹、样本来源和回放数据明确显示所属连接与从站。历史数值表每页 500 条，可翻页访问完整会话，CSV 始终导出全量原始精度；加载会话期间显示读取状态。

模板编辑支持在属性检查器中保存点位；删除点位须确认，并清理绑定从站的趋势引用，不修改既有历史 Session 的 Schema Snapshot。

## Polling / Cache

- 主站 Connection 在线且 Slave 启用后，绑定 Template 中全部 Block 按各自周期持续 Poll。
- Block 周期允许 0–60000 ms 整数，0 表示尽快采集，多个到期块公平轮转。连接统一配置应答超时、读取重试次数和重试间隔，重试间隔支持 0 ms，旧工作区缺省沿用 50 ms。轮询重试等待期间其他到期块继续执行，采集周期与 Host 界面刷新周期分别配置。
- 连接支持自动或手动恢复策略，自动恢复使用可配置的固定重连间隔，缺省 1000 ms。连接或启动超时独立配置，缺省 3000 ms，控制 TCP 建连、串口打开及本机监听启动的最长等待。应答超时控制一次 Modbus 请求的响应等待。手动停止取消待恢复任务，正在连接时可取消等待。
- 页面选择只改变展示，不改变后台 Poll 范围。
- Realtime / Trend / Canvas / 采样缓冲 复用同一 Block Cache；断开 Connection 或禁用 Slave 后停止对应 Poll。
- 高负载只告警，不自动降频。

### 从站通信状态

- 主站按从站实例显示「待确认」「在线」「离线」「停用」。建连期间显示「连接中」。连接已打开的启用实例从「待确认」开始，收到匹配的正常应答或设备异常应答后转为「在线」，并更新该实例的最后应答时间。
- 从最后一次有效应答起，各可读数据块都连续三次完成轮询及适用重试且没有目标从站应答，设备转为「离线」。同一块的任一可读片段有目标应答即视为设备可达。连接断开立即显示「离线」，重连与重新启用后重新判定。
- `0x02` 表示目标从站在线且读取地址或范围无效。读取异常显示异常码，保留已确认的数据。`0x0A`、`0x0B` 表示网关路径异常或目标没有应答，计入目标无应答轮询。

## Write Semantics（主站）

- Value 始终是最后一次 confirmed value；Editing 时后台 Poll 不覆盖输入，Writing 时 pending 与 confirmed 分离。
- ro/rw/wo 分别表示只读、读写、只写。02/04 地址区固定 ro，旧工作区中的 ro/rw 保持原有权限。
- 写入前的最新值读取失败时，不发送写请求，结束等待并明确显示“未发送”及预读失败原因；允许检查连接后重新尝试。
- 合法且匹配地址、写值/数量/掩码的正常应答结算为成功。Exception 结算为拒绝，Timeout、Transport Error 或始终未获得匹配应答结算为未知。写请求发送一次，设备值随正常采集更新。
- Coil 单 Bool 使用 FC05，完整寄存器及多字类型直接编码后使用 FC06 / FC16。
- 读写 Holding Register 的部分字段执行 Read latest → Mask/Merge → FC06，预读使用设备最新值。只写部分字段使用 FC22，设备须支持该功能，设备拒绝时保留明确的失败结果。
- Main 单独保存最后下发值、时间、结果与最近成功命令，随 Host 最新值读取提供。只写控件明确显示“命令”或“上次写入”，开关根据最近成功命令展示。命令记录在运行内存保留，工作区保存访问权限。

## 主站积木脚本

- 「记录日志」在运行结果中记录执行时间、文字及可选的变量或点位当前确认值，点击记录可定位原积木。缺少值时显示原因，流程继续。步骤记录按本次运行保留最近 250 条。事件脚本另保留最近 64 条打印及失败消息，可在同一面板筛选查看。
- 断点随流程保存和导出。主站在可执行积木前处理断点、暂停和单步，循环进入下一轮时也可再次命中。暂停时可查看已赋值变量和本次待写值。继续后使用刚核对过的写值，并通过现有写入确认流程。主站通信调度独立运行。

- 脚本横向切换。积木分类和托盘默认并排展开，画布为托盘留位，收起后可恢复上次分类。搜索支持跨分类查找积木和主流程的具名变量，结果可直接拖入画布。同一脚本页面切换流程时保留托盘状态。新条件槽用真假拨钮表示固定值，拖入条件积木后按连接表达式判断。
- 检查器可切换 Lua、变量和校验。变量在草稿阶段按作用域列出，运行及暂停时显示实际值，流程结束后保留末值。函数区分本次调用和上次调用的参数、局部值。点击名称定位积木，改动执行逻辑后须重新运行才能显示新版的值。

- 可替换值槽接受常量、点位确认值或运行变量，Main 按目标类型解析和校验。条件支持显式布尔字面值，「否则如果」依次判断并只执行第一个成立的分支。
- 主循环无固定间隔，每轮交还脚本调度器，可跳出最近的循环或停止整次运行。带事件入口的计数循环支持最多一百万次，执行器保留循环位置。尝试执行提供执行区及出错区，错误处理中可判断当前失败类别，停止优先于错误恢复。动态高风险写在实际值确定后等待确认。
- 每个脚本最多一个启用的 `on_start`、一个 `on_run` 和每个定时通道一个 `on_timer`。新画布展示启动与周期入口，空 `on_run` 不参与调度。主进程按单调时钟独立调用 `on_run`，默认 100 ms。周期可在运行时修改，支持 10–120000 ms，启动段可以在周期回调运行期间继续计算或等待 I/O。
- T0–T7 支持单次、指定次数和循环。重启通道重新计时，停止通道取消后续触发。每个来源只运行一个回调，慢回调期间最多合并一次待执行触发。全部任务结束且无活动事件源时完成，否则空闲时显示「等待事件」。断点冻结调度时钟，单步放行一个步骤，停止整次运行会取消定时器和排队操作。

- 在「主站脚本」中使用 Blockly 编辑流程。开始积木连接设备操作、等待条件、断言、延时、分支、循环及错误处理。条件支持从站通信状态、确认值比较、数值范围、与变量比较和「与」「或」「非」嵌套组合。
- 保存变量、固定值比较、范围判断和变量比较使用主站缓存中最新的有效确认值。「如果」和「断言」立即判断，缺少必要数据时报告原因。需要写后的反馈值时，在写入之后对反馈点位显式使用「等待新采样」。
- 流程保存在工作区，用稳定 ID 绑定设备。使用独立 JSON 文件导入或导出流程，跨工作区导入后可重新绑定设备和点位。只读 Lua 随积木更新，可复制到文本文件。积木、代码行与运行日志支持相互定位。选中积木的代码范围与 Main 上报的执行位置分别标示，断点和单步时按需滚动。「校验」检查草稿的可执行结构、参数和工作区绑定，并提供问题积木定位。
- 运行时校验全部绑定和值。每次只运行一个主站流程，运行前汇总确认高风险写入。执行接受匹配的写应答。「等待条件」进入时检查当前状态，此后按相关采样和从站状态通知复查。
- 运行变量可显式赋值和递增。赋值保留读入值的类型，四则运算及递增只接受有限数值，发生求值错误时保留变量原值。两个值可按相同类型比较，大小比较使用数值。日志的可选值槽可以承载计算结果。
- 自定义函数属于当前脚本，通过稳定的定义 ID 引用。流程函数执行步骤，支持断点和单步。计算函数返回一个值，可用于条件、计算或设备步骤的值槽。参数按位置传值，局部变量独立于调用者，函数返回或抛错后恢复调用者作用域。静态校验检查重名、引用、参数及递归环。
- Lua 预览为自定义函数生成本地声明和直接调用，按函数作用域处理形参与变量。新积木默认使用英文标识符，旧工作区名称在预览中取得合法且互不冲突的别名。设备读写、确认采样和等待通过宿主接口表示。
- 运行结果显示当前步骤、实际值或失败原因。点击步骤可定位积木。停止结束后续步骤并取消排队写入，在途写入继续按协议确认。
- 周期读和手动刷新按连续可读范围拆分，跳过只写映射独占的地址。存在可读别名的地址继续采集，纯只写块作为命令目标。缓存记录逐地址有效性，每次响应只更新实际覆盖的点位和采样。
- 高风险二次确认按点位配置，设置页说明当前写应答确认、预读合并和掩码写入流程。

## Scale / Offset

- String 写入按编码后的字节数校验，长度 1–246；超长、ASCII 中的非 ASCII 字符和填充用 NUL 字符在提交前拒绝，不静默截断。UTF-8 的中文和 emoji 计入实际字节长度；短文本以零填充剩余存储。
- Float32 写入必须能编码为有限的 IEEE-754 单精度值；大于其有限范围的数在发送前拒绝，不能以确认写入的方式变成 Infinity。

- Engineering = Raw × Scale + Offset；Write Raw = (Engineering − Offset) / Scale。
- Scale=0、Raw 越界、NaN、±∞ 在发送前拒绝；整数/BitField 逆变换后量化并校验范围。

## Realtime / Trend / History

- 实时页在尚未选中从站且工作区已有从站时默认选择首个从站，避免已配置数据却显示空白。
- Numeric 用折线；Bool 用数字波形 + edge time；Enum 用命名状态段；String 用变化事件。
- Main 在成功确认采集后追加有效样本，保留 UTC 毫秒时间、单调时间、递增序号和原始值。同值的连续采集分别保留，通信错误沿用连接/数据块状态。
- 缓冲按实例点位共享，趋势组和画布曲线建立引用，隐藏页面后后台继续采样。容量默认 10,000，单点 10–100,000，总启用容量最多 2,000,000 点。添加信号时配置容量，趋势、曲线与实例入口修改同一配置并显示引用。
- Host 按独立周期获取所需最新值和新增样本，前端共享缓存按核对时效复用并合并在途请求。普通数值控件使用最新值，需要曲线的点位启用时序缓冲。曲线以真实时间对齐，光标逐信号显示实际时间、序号和值。
- 趋势与画布曲线按显示时间窗加载，扩大窗口时补取仍在 Main 缓冲内的历史，后续按序号增量读取。数值样本使用二进制列传输，按点数及采样字节预算分页。Main CSV 导出直接使用原始缓冲与完整精度。
- 趋势组、曲线与点位提供原始 CSV 文件导出，支持 UTC 时间范围，Main 截取稳定快照并写文件。满容量覆盖最旧样本，退出程序释放内存。
- History 读取已有 SQLite Session、Schema Snapshot、事件和原始通信，提供查看、回放、备注及导出。趋势与曲线通过点位采样缓冲导出新数据。

## Streaming Parser / Recovery

- 接收链路支持任意分片、连续多帧及半包/粘包混合；坏帧之后的合法帧仍须恢复解析，且等待和缓冲有界。
- 合法 Exception Response、结构合法但不匹配当前请求的 Unexpected Response、坏帧及超时分别进入通信诊断，保留定位所需的原始字节和原因。通信列表按报文展示独立 TX 请求行和可选 RX 响应行，新报文置顶、同一事务共享 `traceId` 详情；超时无 RX。具体分类、尺寸与恢复策略见[架构](architecture.md#modbus-client-core)及 [RTU](protocol/02-rtu-framing.md) / [TCP](protocol/03-tcp-framing.md) 分帧说明。

## Diagnosis / Import

- RTU Scanner 扫描 Unit ID；Temporary Read 是单次请求，成功结果可保存为 Block。
- Temporary Read 默认数量为 10 个寄存器。Scanner 支持中途停止、保留部分结果并恢复当前连接轮询。目标从站的匹配应答可发现从站，包含设备异常应答。网关返回的 `0x0A`、`0x0B` 记录在通信诊断中。界面显示实际重试次数与响应类型。
- 扫描进度明确区分已检查的从站地址数、当前探测 Unit 和已发现从站数，不把“已检查”当成发现设备。临时读取必须显示读取中和持久的失败反馈（超时、异常码/含义、传输/协议错误、IPC 错误），包含本次请求参数和通信诊断入口；失败后不残留旧成功数据。已成功结果的地址及保存为 Block 的参数绑定实际请求，不随后续表单编辑改变。
- Scanner 的 Unit 范围下方设默认折叠的“高级扫描配置”：读取 FC01/02/03/04、0-based 起始地址、单次超时及重试次数；默认 FC03 / 地址 0 / 150 ms / 重试沿用连接，读取数量固定为 1。折叠后设置仍生效，扫描期间锁定；只影响当前扫描，不改变连接的周期读写配置。
- 常用扫描范围可一键预填 1–16、1–32、1–64 或 1–247；仍由用户启动扫描，扫描期间不允许改范围。
- Raw Inspector 只解释当前 Block Cache，不额外请求设备。
- Connection Health 按独立 60 秒时间窗口统计 request rate、P50/P95、Timeout、CRC、Exception 和实际周期。RTU 占用按实际串口参数计算，TCP 展示 Modbus 字节吞吐。明细记录达到保留上限时统计窗口继续完整维护。
- 通信明细在 Main 有界保存，可见通信页按游标和连接批量获取，暂停保存显示副本，清空更新读取代次。常规状态同步携带轻量写命令结果。
- Point ↔ Transaction 通过稳定 `traceId` + source metadata 双向追踪。
- 通信帧详情可复制请求和响应的原始 Hex；无响应时不提供响应复制。
- Import 支持 XLSX / CSV / JSON / Clipboard，先 Mapping + Preview；PLC Reference Address 仅在 Import 层转 0-based；Block overlap 必须阻止。

## Workspace / Persistence

- Workspace schema v2 增加画布定义与多实例工作台布局；打开 v0/v1 文件时迁移，拒绝不支持的未来版本。

- 默认配置、数据库、缓存、日志和临时文件跟随选定的可写存储根目录；失败不得静默回退 AppData。具体优先级、Portable / Setup 行为与测试隔离见 [AGENTS.md](../AGENTS.md) 和[开发说明](development.md#数据缓存与测试隔离)。
- Workspace 使用带 `schemaVersion` 的 `.workspace.json`，自动保存并支持另存为、导入、导出。导出生成独立文件，不改变当前自动保存路径。
- Workspace 保存 Connection、Slave、共享 Template 定义/绑定、Trend Group 和可移植布局；本机 Window/Sidebar 偏好放 app `userData`。
- 画布定义只在显式保存时提交，未保存的编辑属于页面草稿；标签列表、当前页与对象选择自动保存到工作区。重启后标签回到主窗口；再次弹出使用本机记录的窗口位置，并限制在当前显示器工作区。
- 自动保存使用临时文件 + 原子替换；导入失败不破坏当前 Workspace。
- 设置页提供工作区文件操作、时区和清空通信诊断，说明当前缓冲保留方式及既有历史库位置。固定地址规则、写入流程和当前仅有的一种语言以说明呈现。文件操作失败显示原因，取消文件选择正常返回。
- History 使用独立 SQLite `history.db`；10 GB 只提醒，不自动删除，也不代表已验证的可用容量或回放性能。当前验收目标为单会话 100 万数值样本，实测边界见[容量报告](benchmarks/history-capacity-2026-09-25.md)。实时事务在有界内存诊断中携带来源元数据和 Raw ADU/PDU。旧历史库中的事务元数据及原始通信可继续读取，历史服务提供备注写入。

## 多实例工作台与自由组态画布

- 所有模块均可打开多个标签实例，最多同时 40 页。普通导航激活已打开的同类页，“新建页面”或 Ctrl+单击主要模块导航新建实例；“打开当前页面副本”复用对象选择与通信筛选，然后独立操作。
- 页面选择、筛选、排序、滚动、趋势暂停/跟随与时间窗口、画布缩放和编辑草稿按实例隔离。趋势时间窗口默认来自趋势组定义，调整仅作用于当前页面；切换趋势组时采用新组默认值。模板、趋势组信号定义、画布定义和所有设备确认值共享。
- 弹出/回入移动同一视图，保留临时状态；独立窗口 X 默认回入，标签 X 才关闭页面。关闭含未提交编辑的页面须选择取消或丢弃；主窗口退出时处理草稿并关闭全部独立窗口，通信与记录由 Main 统一收尾。
- 工作区可保存最多 100 张画布，每张最多 500 个控件。支持独立文字标签、数值显示（含 Bool/String 等点位显示）、指示灯、按钮、Bool 开关、数值输入、仪表、多信号趋势图和容器。基础控件默认紧凑透明，名称、背景、边框按需开启；“适合内容”收紧控件尺寸。
- 容器保存父子关系和相对坐标，最多嵌套 8 层。支持添加到容器、加入/移出、整体移动、分组/解除、包含子树的复制/删除；解除容器保持画布坐标，加入容器时保持位置或约束到其边界。循环、缺失父级和越界在保存时原子拒绝。
- 单曲线最多 16 个数值信号，颜色可配，支持图例显隐、十字游标、时间范围缩放/平移、暂停/跟随。两种单位使用左右轴，更多单位分图；暂停保留采样副本，窗口移动保留缩放和图例状态，数据仍复用共享缓存。采用 Apache ECharts 并随包保留许可/NOTICE。
- 曲线实时跟随时，放大后的视区随时间推进。暂停锁定显示快照和绝对时间范围，恢复后取得最新窗口。多个 Host 按各自范围查询共享采样缓冲，重叠区间复用，不相交时段分别查询。容量覆盖后清理实时数据，并明确提示缺口及请求范围的可用状态。
- 仪表样式包括半圆、指针表盘、横向条形、纵向条形和液位，使用同一已确认值、量程与单位。输入类型包括数值、String 文本、枚举下拉、步进和滑块。下拉复用点位 enumMap，Bool 提供 OFF/ON。步进和滑块修改待写值，显式提交后才写设备，数值范围按控件配置校验。文本允许显式写入空字符串。旧画布缺省为半圆仪表与数值输入。
- 控件样式独立保存，提供文字颜色、字号、字重、对齐、边框颜色/粗细、圆角，以及适用控件的内边距。输入和按钮支持描边、柔和填充、实色、下划线外观，支持恢复默认。内边距和输入字号变化同步调整外框尺寸，样式随复制和保存恢复。
- 指示灯支持亮灭独立文字/颜色及纯色、线性、径向渐变。多状态可配置最多 64 条等值或区间规则，包含可选上下限与端点包含关系，按列表顺序取第一条匹配。枚举可辅助填入状态，手动状态表适用于普通数值。未匹配/无效值使用可配置默认状态，通信质量独立提示。所有判定使用确认值，枚举使用 rawNumber，普通数值使用 engNumber，Bool 使用 0/1。离线保留最后确认状态。
- 编辑模式锁定设备写入，支持控件拖入/点击添加、框选/Shift 多选、复制、置顶/置底、删除、撤销/重做。画布提供独立网格显示及吸附开关，间距默认 8 px，可配置 2–128 px，随工作区保存。网格以画布原点定位，支持缩放和嵌套容器，Alt 拖动/缩放临时自由调整，方向键微调 1 px，Shift+方向键按当前网格间距移动。
- 同层级多选支持左、水平居中、右、顶、垂直居中、底对齐。三个以上控件可水平/垂直等间距排列，固定按位置排序后的首尾控件，均分边缘空隙，支持撤销和重做。画布独立缩放与滚动，工具栏在窄窗口换行展示。
- 编辑态“状态预览”按视图和控件临时保存模拟值、数据状态及控件外观。支持灯的亮灭/任意规则/默认状态、仪表量程快捷值、数值/文本/Bool/枚举、独立示例曲线及写控件的正常/禁用/写入中/失败。预览明确标记，模拟数据仅保存在当前视图。单项恢复跟随或清除全部；运行、切换画布、关闭视图清除，弹出/回入保留。
- 控件按 `slaveId + pointId` 绑定，复用点位单位、精度、类型与访问权限；无绑定、失效绑定、离线、未采集和通信异常明确显示，不能把旧值当成在线新值。
- 指示灯的「绑定变量」可按 `slaveId` 选择只读的设备通信状态，默认使用状态文字与配色。可继续编辑多状态规则或切换为在线时亮灯。设备通信状态直接消费 Main 的运行状态，复用设备已有通信。
- 写控件通过既有 `point.write`，数值输入须显式提交，按钮写入配置值，开关写入 0/1。尊重点位权限、高风险确认、必要的预读/掩码写及写应答结果，草稿和 pending 独立于 Block Cache。只写点位可绑定写控件，数值显示、灯、仪表和曲线选择可读点位。
- 同一画布的并发保存检查 revision，过期草稿不得覆盖新版本；保留草稿并允许取消或重新载入。已有点位、数据块、连接、从站与模板名称的表单保存携带编辑基线以检测并行修改。
